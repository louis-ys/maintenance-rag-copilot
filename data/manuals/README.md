# Manual setup

The public portfolio edition does **not** redistribute the source manufacturer's PDF manual.

This project was developed against Hyosung Heavy Industries' Korean low-voltage motor operation and maintenance manual, which is publicly available from the manufacturer's website.

Official source:
- https://www.hyosungheavyindustries.com/kr/technical/low_voltage_motors_manual.do
- https://www.hyosungheavyindustries.com/kr/customer/download-center/1578

To run the project locally:

1. Download the Korean low-voltage motor manual from the official Hyosung Heavy Industries source.
2. Save the PDF in this directory as:
   `hyosung_motor_manual_ko.pdf`
3. Install dependencies and run the application as described in the repository README.

The manual remains the property of its original rights holder. This repository is an independent portfolio prototype and is not affiliated with or endorsed by Hyosung Heavy Industries.
